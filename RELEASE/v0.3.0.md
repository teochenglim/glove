## Built

Verified (2026-11-04, local macOS arm64, Go 1.27.3):
- `make check` + `make race` green; 18 enforced PRD bullets, 0 under-tested; all nine ACs carry 2 tests each.
- Audit: one record per hook invocation with every §5.4 field (`TestAC_0_3_1_*`); 10k-record block/24h query correct and under 200ms (`TestAC_0_3_2_*`); 20-dangerous-command fixture leaks zero plaintext by default and `--audit-verbose` redacts private keys, Authorization headers, token pairs and base64 blobs (`TestAC_0_3_3_*`); 15 MB stream rotates at the 10 MB cap and the 5-file window holds (`TestAC_0_3_4_*`); per-OS path resolution incl. `%LOCALAPPDATA%\glove` (`TestAC_0_3_5_*`).
- Policy: protected path added via policy blocks the very next hook invocation with nothing to restart (`TestAC_0_3_6_policy_reload_enforces`); policy changes emit exactly one `policy_reload` audit event, unchanged policies none (`…_audited`); invalid policy fails the hook closed (deny, exit 2) naming the key, and `policy validate` reports the parser's line for syntax errors and key paths for schema errors (`TestAC_0_3_7_*`); fast-mode plumbing flags `model_available: false` and stays within the 20ms P95 budget (`TestAC_0_3_8_*`); project `.glove.toml` overrides user scalars and concatenates pattern lists, discovery walks up from nested cwds (`TestAC_0_3_9_*`).
- Demo transcript (throwaway `$HOME`): `audit tail` table, `audit query --decision block`, `audit export --format csv`, `policy validate` (valid + syntax error with line/caret), policy reload event with source attribution, user-protected path blocking `cat ~/secrets/key.pem` (exit 2), `check --policy` with a project hard-block, `doctor` policy/audit lines.
- Dependency: `github.com/BurntSushi/toml v1.6.0` (row in `RELEASE.md` §1).

Limits: live Claude Code session still pending the user's smoke check (v0.1.0 item); the Windows audit path is unit-tested per-OS but not exercised on Windows hardware (v0.6.0 CI matrix); rotation verified at real 10 MB/15 MB scale plus scaled-down rotation-cap logic — multi-day accumulation unexercised; the policy_reload detector keys on the audit-dir state file, which `--audit-verbose`-style per-session overrides do not bypass (by design).
