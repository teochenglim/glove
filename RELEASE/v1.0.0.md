## The 1.0.0 promise (what the number means)

**Blockers without evidence are popup dialogs. SIEMs without enforcement are dashboards. glove is the enforcement point that produces the evidence** — every agent tool call decided *before* execution under the only-ever-tightens invariant and fail-closed everywhere, every decision recorded in a tamper-evident, ATT&CK-tagged, machine-attributable, SIEM-ingestible trail. That is the product 1.0.0 certifies.

1.0.0 is not a feature release. It is the moment four contracts stop moving and become promises others can build on:

- **`contract.Verdict` (§5.3)** — the decision envelope every agent integration and `serve` consumer depends on. Frozen: no field, tag, or enum change without a schema-version bump and owner sign-off (ADR 2). Adapters and integrations can compile against it and outlive glove releases.
- **The CLI surface (§6)** — `hook / check / install / uninstall / list / doctor / audit (tail/query/export/verify/stats) / policy (validate/pack/import) / serve / version`. Frozen: a rename after 1.0.0 is a breaking change. Scripts, CI jobs, and the install docs target these names.
- **`policy.toml` (§5.5)** — the tuning and fleet surface: `[general]`, `[rules]` (+ `[rules.techniques]`), `[paths]`, `[laya]`, `[audit.sink]`, `[correlation]`, `[agents.*]`. Frozen: org baselines, `policy pack` bundles, and the cookbook keep working unchanged.
- **The audit JSONL schema (§5.4, version 2)** — the evidence format: hash chain, machine identity, ATT&CK tags, event types. Frozen: SIEM integrations, `audit verify`, and downstream parsers keep parsing every 1.x record. Schema evolution from here on is a versioned migration, never a silent change.

The boundary stays exactly where the PRD drew it (§3.3): glove guards the **hand**, not the mind — it evaluates `tool_name` + `tool_input` only, keeps zero network on the decision path, and is invoked software, not a runtime. Local, single-binary, opt-in forwarding, off by default. Windows returns only with an interactive Windows pass (PRD §8); new agents, new schemas, and new decision semantics are **1.1.0** work — the 1.x stability commitment (12 months of security patches per minor, stated in the README) is the product now.
