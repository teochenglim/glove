## Built

Verified (2026-11-04, local macOS arm64, Go 1.27.3):
- `make check` + `make race` green; AC tests 2×5; 10-case hook fixture (`testdata/claude_hook_cases.json`) green.
- CLI transcript: `rm -rf /` → block/critical (`rm_root`); `cat ~/.ssh/id_rsa` → block/high; `cat ~/.ssh/config` → allow (§2.2 distinction); `sudo apt install` → review/high; `ls -la` → allow.
- Hook: block → exit 2, allow/review → exit 0; broken stdin → deny + exit 2 (fail closed, §8/ADR 1).
- Install (throwaway `$HOME`): diff shown, backup written, second install a no-op, broken JSON → clear error, original untouched, no backup.
- `doctor --bench hook`: median 4.7ms / p95 6.4ms over 20 runs — PASS vs the 15ms budget (§8); CI gate is `TestAC_0_1_5_hook_cold_start_budget`.
- Dependencies: `spf13/cobra v1.10.2` (scaffold), `gopkg.in/yaml.v3 v3.0.1`, `google/uuid v1.6.0` (rows in `RELEASE.md` §1).

Deviations: RE2 has no negative lookahead, so `git_force_push` ships as `--force([^a-zA-Z0-9_-]|$)` (matches bare `--force`, never `--force-with-lease`); rule tests cover it. Non-shell tools claim protected paths only.

Limits: live Claude Code session not exercised (user smoke check, pending); the v0.1.0 tag CI/Release runs failed on the ac-map locale bug + doctor smoke assertion (fixed after the tag); govulncheck not installed locally.
