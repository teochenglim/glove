## Scope

- `cmd/glove/main.go` with subcommands: `hook`, `check`, `install`, `version` (cobra)
- `internal/decision/rule.go` — Layer 0: hard-block, force-confirm, protected-path rules from `internal/rules/builtin.yaml` (PRD Appendix B seed set)
- `internal/adapter/adapter.go` — the `Adapter` interface (PRD §5.1); `internal/adapter/claude.go` — reads `.claude/settings.json` / `~/.claude/settings.json`, writes the `PreToolUse` hook, shows a diff, backs up to `settings.json.glove.bak`
- `glove check "<cmd>"` wired to Layer 0 only — first end-to-end path
- `glove install claude-code` runs two test calls (`ls -la` → allow, `rm -rf /` → block) and prints the result
- `glove doctor --bench hook` (trivial in 0.1.0) measuring cold-start latency (PRD §10.3)

## Notes

- Dependencies introduced in this release: `gopkg.in/yaml.v3 v3.0.1` (builtin.yaml), `github.com/google/uuid v1.6.0` (audit IDs) — rows in `RELEASE.md` §1. `spf13/cobra v1.10.2` came with the scaffold.
- `contract.Verdict` is frozen from the day it ships (§10.4): no field change without a schema-version bump and explicit sign-off. The freeze test in `pkg/contract` is the tripwire.
- No OpenAPI for this repo: the public API is the `pkg/contract` types + the hook stdout protocol, not HTTP (ADR 2). `serve`'s `/evaluate` (0.4.0) reuses `contract.Verdict`.
- RE2 has no negative lookahead, so the PRD Appendix B sketch `--force(?!-with-lease)` is shipped as `--force([^a-zA-Z0-9_-]|$)` (matches bare `--force`, never `--force-with-lease`); covered by rule tests.
- Fail-closed policy (§8, ADR 1): hook internal errors — engine load failure, unknown agent, unparseable stdin — return a deny verdict with exit 2, never an open gate. Layer 0 stays honest about what it claims: a bare token like `.env` is claimed, exotic composition is left to Layer 1 (v0.2.0).
- Non-shell tools (Edit, Write, MCP): Layer 0 only claims protected paths found in any string field of the tool input.
- Out of scope (PRD §7): Layer 1 chain splitting, Laya, audit log, any other Agent, `uninstall`/`list`/`serve` CLI surface.

## Built

Verified (2026-11-04, local macOS arm64, Go 1.27.3):
- `make check` green (fmt-check, vet, ac-map, test, version-check); `make race` green.
- AC tests: `TestAC_0_1_1_*` (2), `TestAC_0_1_2_*` (2), `TestAC_0_1_3_*` (2), `TestAC_0_1_4_*` (2), `TestAC_0_1_5_*` (2) — all pass; 10-case hook fixture set (`testdata/claude_hook_cases.json`) green.
- CLI transcript: `glove check "rm -rf /"` → block/critical with `rm_root` reason; `cat ~/.ssh/id_rsa` → block/high (protected path); `cat ~/.ssh/config` → allow (PRD §2.2 distinction); `sudo apt install` → review/high; `ls -la` → allow.
- Hook: `{"tool_name":"Bash","tool_input":{"command":"rm -rf /"}}` → `permissionDecision: "deny"` on stdout, **exit 2**; `ls -la` → allow, exit 0; `git push --force` → ask, exit 0; broken stdin → deny + exit 2 (fail closed).
- Install (in a throwaway `$HOME`): diff shown, `settings.json.glove.bak` written, second install = no changes, broken JSON → clear error + original untouched + no backup.
- `glove doctor --bench hook` on M-series local hardware: min 4.2ms / median 4.7ms / p95 6.4ms / max 7.4ms over 20 runs — **PASS against the 15ms budget** (§8). CI enforces the same gate via `TestAC_0_1_5_hook_cold_start_budget`.

Limits: the **live Claude Code session** has not been exercised (needs this binary on PATH + `glove install claude-code` on the user's machine — run before cutting the tag); CI has not run on a tag yet; Windows/Linux/arm64 targets unexercised locally.
