## Scope notes (pre-implementation — written when built, red tests first)

- **Correlation is tighten-only by construction:** it feeds the *undecidable* path only — it may raise allow → review, never downgrade block or review, and never touches a Layer 0/1 verdict. The invariant test extends; correlation is state derived from the audit trail (keyed by `session_id`), so one-shot hook processes need no new daemon — the exact mechanism (serve-held in memory vs bounded audit-tail scan offline) is decided at implementation and must not breach the §8 budgets either way.
- **No cross-machine service** (PRD §3.3): bundles are files — the fleet story stays sneakernet/scm; `pack`/`import` are CLI operations off the hook path (no decision-path latency impact).
- **New audit event type** `policy_import` joins `policy_reload`; schema evolution (if any) rides the 0.7.0 versioned audit schema — this is the last release before the freeze where event types can be added freely.
- **Dependencies:** none expected — checksums via stdlib `crypto/sha256`. If signing beyond checksums is wanted (e.g. minisign), that is a new locked-list row decided at implementation, not assumed.
- **Tests above are the plan** (house naming, ≥ 2 per AC); none exist yet — the status stays `planned` until the release checklist ticks, per `scripts/ac-map.sh`.
