## Scope notes (pre-implementation — written when built, red tests first)

- **Correlation is tighten-only by construction:** it feeds the *undecidable* path only — it may raise allow → review, never downgrade block or review, and never touches a Layer 0/1 verdict. The invariant test extends; correlation is state derived from the audit trail (keyed by `session_id`), so one-shot hook processes need no new daemon — the exact mechanism (serve-held in memory vs bounded audit-tail scan offline) is decided at implementation and must not breach the §8 budgets either way.
- **No cross-machine service** (PRD §3.3): bundles are files — the fleet story stays sneakernet/scm; `pack`/`import` are CLI operations off the hook path (no decision-path latency impact).
- **New audit event type** `policy_import` joins `policy_reload`; schema evolution (if any) rides the 0.7.0 versioned audit schema — this is the last release before the freeze where event types can be added freely.
- **Dependencies:** none expected — checksums via stdlib `crypto/sha256`. If signing beyond checksums is wanted (e.g. minisign), that is a new locked-list row decided at implementation, not assumed.
- **Tests above are the plan** (house naming, ≥ 2 per AC); none exist yet — the status stays `planned` until the release checklist ticks, per `scripts/ac-map.sh`.

## Built

Verified (2026-11-05, local macOS arm64, Go 1.27.3): `make check` (45 active ACs, 48/50 enforced PRD bullets, 0 under-tested) + `make race` + `make stress` + `make audit` (govulncheck 0 findings) + `GOOS=windows go vet` green; `scripts/release-check.sh 0.8.0` green. No new dependencies (checksums via stdlib `crypto/sha256`, as the scope notes assumed).

- **Session escalation correlation (AC0.8.1)**: state derives from the audit trail itself, keyed by `session_id` — one-shot hooks need no daemon, exactly as the scope notes resolved it. The scan is bounded by design: the tail windows of the live file (64 KB) and newest rotated file (16 KB), read only for *undecidable* calls (nothing fired, verdict still allow) — decided calls never pay. At/over `[correlation] session_threshold` (0 = default 3; -1 = disabled, since TOML cannot distinguish an explicit 0 from unset) the call tightens to review with a `correlation: …` reason; blocks and deterministic reviews are untouched (their fired list is non-empty) — pinned by `TestAC_0_8_1_correlation_never_loosens`. An unreadable trail degrades to "no escalation": correlation is additive, it has no decision of its own to protect (failure-modes section).
- **`glove audit stats` (AC0.8.2)**: top rules, techniques, agents and decision counts over `--since`, `--top` cut, deterministic tie order. Rule ids parse from reason prefixes with two honesty fixes found in the live transcript: a rule firing twice in one record (the 0.2-era raw+segment double pass) counts **once per record** — stats counts records-per-rule, not reasons-per-record — and engine non-rule reasons (`subshell:`, `correlation:`) are excluded so no phantom rules appear. The 10k gate (load + aggregate ≤ 200ms) is asserted in `make stress` (`TestAC_0_8_2_stats_10k_under_200ms`, `requireStress`-gated like the 0.3.0 precedent); CI keeps the deterministic correctness test.
- **Policy bundles (AC0.8.3)**: `glove policy pack <file>` seals the exact policy bytes with origin metadata (sources, glove version, pack time) and a SHA-256 checksum over **both** — tampering with either half is detected. Pack validates first: a bundle of an invalid policy is refused at the source. `glove policy import` verifies BEFORE any write (destination untouched on refusal, no event), shows the same compact diff installs use (`adapter.WriteDiff`), installs 0600, and emits a `policy_import` audit event carrying the checksum (event type joins the v0.7.0 versioned schema). `--dry-run` verifies + diffs without writing. Bundles are files — no cross-machine service (§3.3).
- Live transcript: 3 blocks in one session → 4th undecidable call rendered `ask` with the correlation reason; `audit stats` honest (`rm_root 3` for 3 decisions, no phantom rules); tampered bundle refused with checksum mismatch and destination absent; clean import installed the exact bytes + `policy_import` event; `audit verify` green over the mixed log.

Limits:
- Correlation counts within the bounded tail window — a session whose old denies rotated past both windows is treated as cold (documented; the alternative — full-log scans on the hook path — is what the bounded design refuses to pay for).
- The 10k stats budget is release-hardware evidence (`make stress`), not a CI gate, per the 0.6.2 stress split.
- Bundles carry a checksum, not a signature — authenticity rides distribution channel integrity; asymmetric signing would be a new locked-list dependency and is deferred (scope note anticipated this decision).
- External proofs (CI streak, signing certs, outside tester, 24h soak) remain with the user, unchanged.
