# RELEASE v0.6.4: windows deferred (patch)

**Status:** ready (untagged — cut together with the v0.6.4 tag)
**Patch gate:** scope change, no AC change (RELEASE.md §3 versioning). Maintainer decision after four consecutive windows-lane CI failures (v0.5.0 → v0.6.3), every one test plumbing and none affecting the product.
**Depends on:** v0.6.3 (tagged)
**Requirements:** none new — PRD §8 (platforms) and §9 (Windows Authenticode) amended in the same change

## Built

- **CI**: the windows runner and its short-test step are removed — the matrix is exactly ubuntu/amd64 + macos/arm64 with one ungated `make check` each. Combined with the v0.6.3 trigger discipline, a release produces exactly one CI run of two green lanes or a real failure.
- **Release**: the windows/amd64 artifact and `.exe` packaging are removed — four platforms (linux/mac × amd64/arm64).
- **Guarded against creep**: the config-as-contract tests now assert the deferral — exactly two CI runners, no `windows/amd64` in the release matrix, no `-short` step — so windows cannot quietly reappear in a workflow edit.
- **What stays**: windows-aware product code (`%USERPROFILE%`/`%LOCALAPPDATA%` path resolution, the shim's win32 branch, the string-level AC0.6.6 tests — all green on the POSIX runners), `GOOS=windows go vet`, and the cross-compile proof of all five targets in `make stress`. The return ticket is recorded: PRD §8 + AGENTS.md require an interactive Windows pass before windows returns; platform facts preserved in `benchmarks/README.md` (spawn 57.1ms median on the runner; CRLF pitfalls pinned via `.gitattributes`; `os.UserHomeDir` reads `USERPROFILE`).

Verified (2026-11-04, local macOS arm64): `make check` (36 active ACs, 0 under-tested) + `make race` green; `GOOS=windows go vet` clean; `make stress` cross-compile still proves all five targets.

## Limits

- Windows artifacts will not ship from v0.6.4 tags until the deferral is lifted (PRD §8); v0.6.3 was the last tag carrying a windows artifact.
- The CI green-streak semantics of AC0.6.1 accrue per tag + PR (tags-only trigger, v0.6.3), across two lanes.
