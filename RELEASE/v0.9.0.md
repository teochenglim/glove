Anything discovered late gets its own 1.x, not a squeeze-in here.
- **Install script honesty:** `curl | sh` verifies the *downloaded artifact* checksum, not the script itself; the script pins the release URL and refuses a checksum mismatch. It never bypasses glove's own fail-closed story.
- **Homebrew:** the formula lives here (`packaging/homebrew/`), the tap repo (`homebrew-<user>/`) is a maintainer repo — the AC tests assert formula correctness against the release artifact layout; the live install is a human gate.
- **Benchmarks:** sink and verify are off the decision path by design (0.7.0) — the re-measurement proves it (verify is offline CLI; sink adds nothing to the hook path), so the §8 budgets come out unchanged or better.
- **Tests above are the plan** (house naming, ≥ 2 per AC); none exist yet — the status stays `planned` until the release checklist ticks, per `scripts/ac-map.sh`.

## Built

Verified (2026-11-05, local macOS arm64, Go 1.27.3): `make check` (48 active ACs, 48/50 enforced PRD bullets, 0 under-tested) + `make race` + `make stress` + `make audit` (govulncheck 0 findings) + `GOOS=windows go vet` green; `scripts/release-check.sh 0.9.0` green; semgrep (5 packs + vendored, 265 rules) **0 findings** after this release's CI fix. No new dependencies.

- **Install script (AC0.9.1)**: `scripts/install.sh` — POSIX sh, no jq/API dependency; detects OS/arch, downloads the pinned release asset + `checksums.txt`, verifies the SHA-256 **before** extracting or installing anything (verify-then-unpack: no release byte is unpacked until its hash matches), refuses a mismatch or an unlisted asset loudly with want/got on stderr, installs to `GLOVE_INSTALL_DIR` (default `/usr/local/bin`, guidance to `~/.local/bin` on permission failure), prints the installed `glove version`. `GLOVE_INSTALL_BASE_URL`/`GLOVE_INSTALL_VERSION` overrides exist for sandboxes and airgaps. Honesty carried from the scope notes: the script verifies the artifact, not itself. Tested by driving the real script against an httptest-served release layout: clean install runs and the installed binary reports the version; tampered `checksums.txt` refused with the install dir untouched; unlisted asset refused.
- **Homebrew (AC0.9.1)**: formula at `packaging/homebrew/glove.rb` — four per-platform blocks matching the release workflow's artifact naming (`glove-v<ver>-<goos>-<goarch>.tar.gz`, binary installed as `glove`), Apache-2.0, caveats pointing at `glove install`. Per-release maintenance documented in `packaging/homebrew/README.md`; `scripts/update-homebrew-sha.sh` fills the four sha256 lines from the published `checksums.txt` (placeholder hashes fail the install — the honest failure mode). `TestAC_0_9_1_formula_matches_release_layout` (internal/release) parses release.yml's build matrix and asserts the formula covers exactly those platforms with a sha256 line each, and that the formula version never lags `VERSION` — a workflow rename that breaks the formula fails `make check`. The tap repo and live `brew install` remain the maintainer/outside-tester gates.
- **Hardening pass (AC0.9.2)**: the failure-modes audit now carries the v0.7.0 (sink/verify) and v0.8.0 (correlation/bundles) sections plus a v0.9.0 distribution section, contract-checked by `TestAC_0_9_2_failure_modes_cover_new_paths` (cited-test existence is enforced doc-wide by the 0.6.2 test). `TestAC_0_9_2_new_paths_fail_closed` hammers the new surfaces together: malformed `[audit.sink]` fails the hook closed with the actionable key-path error; `glove audit verify` names the first break of an edited chain; a tampered bundle is refused before any write with no `policy_import` event; an unreadable correlation trail degrades to "no escalation" (the additive-layer contract). En-route CI fix: the v0.7.0/v0.8.0 security-lane reds — `tls.Config{}` in the syslog tcp+tls dial now carries an explicit `MinVersion: tls.VersionTLS12` (Go's own default, made explicit; 1.3 rejected as a floor to keep older on-prem collectors connectable) and the vendored semgrep rules use Semgrepignore-v2-safe `**/` path patterns — 265 rules, 0 findings locally.
- **CHANGELOG + benchmarks (AC0.9.3)**: `CHANGELOG.md` is the verbatim consolidation of RELEASE.md §4 (13 version sections, newest first) — `TestAC_0_9_3_changelog_consolidated` compares section bodies byte-for-byte, so drift fails `make check`; regenerate it whenever §4 changes (the CHANGELOG header says so). Bench re-measured with sink + verify included: `audit verify` over 10,000 chained records **~0.50s** (budget 1s), file sink 50 deliveries + drain **< 1ms** (budget 50ms), syslog udp delivery + drain **~50ms** (dominated by the deliberate 50ms ICMP read window; budget 100ms), webhook bounded by the drain window — recorded in `benchmarks/README.md`; the decision-path §8 budgets are untouched by construction (latency is stamped before the sink is consulted).
